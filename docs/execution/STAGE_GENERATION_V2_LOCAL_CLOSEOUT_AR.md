# إغلاق مرحلة Generation Engine V2 المحلية

الحالة: **مغلقة محلياً** — لا تعني جاهزية Production ولا تسمح باستدعاء KIE أو OpenRouter.

## ما تم تثبيته

- `GenerationIntent` هو الهوية المنطقية الواحدة لمحاولة التوليد، ومستقل عن مفتاح النقل `Idempotency-Key`.
- كل `Quote` يُستهلك مرة واحدة فقط. إعادة الإرسال، حتى بمفاتيح نقل مختلفة، تعيد العملية نفسها ولا تنشئ حجزاً ثانياً.
- المسار الرئيسي الموحد هو:
  - `POST /v2/quotes`
  - `POST /v2/operations`
  - `GET /v2/operations/:operationId`
- لا يوجد أمر `/run` في مسار Creative Space الرئيسي. تأكيد العملية يبدأ التنفيذ تلقائياً، والعميل يتابع الحالة فقط.
- كل تغيير حالة في التنفيذ المحلي يمر عبر `requireLegalTransition` مع Compare-and-Set، رقم إصدار متزايد، جهة مخولة، ودليل.
- التسوية لا تقع إلا بعد نجاح المزود، تخزين الأصل الخاص، التحقق منه، ثم إتاحته للتسليم.

## أدلة الإغلاق

- 100 إعادة إرسال متزامنة لنفس Quote وGenerationIntent تنتج عملية واحدة، Outbox واحداً، وحجزاً واحداً.
- تسلسل إصدارات الحالات يبدأ من 0 ويزداد مرة واحدة لكل انتقال حتى `SETTLED`.
- لا يرسل Creative Space أي طلب إلى endpoint من نوع `/run`.
- الاختبارات المحلية لا تستخدم API مدفوعاً؛ Provider For Test هو البديل الوحيد داخل هذه المرحلة.

## الحدود غير المغلقة للإنتاج

هذه النسخة ما زالت مرجعاً محلياً داخل الذاكرة. قبل أي Production يجب تنفيذ PostgreSQL durable storage بقيود فريدة على Quote وGenerationIntent، Transactional Outbox دائم، Queue/Worker مستقل، مصادقة مستخدم حقيقية بدلاً من `local-user`، وسياسة SLA للاسترداد عند غموض تكلفة المزود. لا يجوز اعتبار هذه المرحلة ضماناً مالياً إنتاجياً قبل إغلاق تلك البوابة.
